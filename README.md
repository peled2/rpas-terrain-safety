# בקרת גובה שטח | RPAS Terrain Safety (PWA)

אפליקציית PWA להצגת קווי גובה וטווחי בטיחות מעל פני הים (**AMSL**) להטסת כלי טיס מאוייש מרחוק באזור הררי.

## יכולות עיקריות

- **קווי גובה רציפים (אדום):** חישוב וקטורי של קו הגובה הנבחר (ברגל AMSL) לאורך כל הר שחוצה את הגובה הנדרש.
- **פוליגון טווח בטיחות:** הצללה אדומה שקופה של כל שטח ההר שמעל הגובה הנבחר + רצועת הבטיחות החיצונית (במטרים או ק״מ), עם קו מתאר אדום בהיר יותר.
- **מנוע חישוב מהיר ב-Web Worker:** שימוש באריחי גובה AWS Terrarium, טרנספורמציית מרחק אוקלידית דו-ממדית (2D EDT) ו-Marching Squares.
- **מניעת תקיעות בזום ותזוזה:** מעטפת חישוב עם מרווח ביטחון (Overscan & Hysteresis), מדרגות רזולוציה בדידות (Zoom Tiers), Cache אריחים בזיכרון ואפשרות **נעילת אזור חישוב**.
- **מפות רקע ומדידת שטח:** מעבר מיידי בין מפת לוויין למפה טופוגרפית ומדידת גובה קרקע מדויק (רגל ומטר) בריחוף או לחיצה על המפה.

## הרצה מקומית

```bash
npm install
npm run dev
```

בדיקות ובניית ייצור:

```bash
npm run lint
npm test
npm run build
```

## פריסה ל-Netlify מ-GitHub

הפרויקט כולל קובץ [`netlify.toml`](./netlify.toml) מוגדר מראש (פקודת בנייה `npm run build`, תיקיית פרסום `dist`, חוקי Cache מתאימים ל-PWA Service Worker ו-SPA Redirect).

1. היכנס ל-[Netlify](https://app.netlify.com/) ובחר **Add new site -> Import an existing project**.
2. בחר **GitHub** ואת המאגר **`peled2/rpas-terrain-safety`**.
3. Netlify תזהה אוטומטית את ההגדרות מתוך `netlify.toml` ותפרסם את האפליקציה עם פריסה אוטומטית בכל `git push` ל-`main`.
